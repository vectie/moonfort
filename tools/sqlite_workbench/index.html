Download displayed records
Open table, query, or member records to download them.
Downloads use the last successful displayed records, even while another request is pending or refused. Table and relationship downloads include only the displayed page. Open a matrix cell or numeric band to download its member records. CSV uses empty cells for NULL and base64 for BLOBs; use typed JSON to preserve types and row locators. CSV retains original text, including formula-like values: import as text in spreadsheet software. Downloading does not authorize sharing.

Save and reopen the SQL editor
A worksheet saves the current SQL, typed parameter editor text and row bound, without running it.
Reopen replaces the SQL editor and clears previous results. It requires the same exact retained bundle, database and artifact, even in a new session. Review or edit it, then press Run read-only query. Files contain no session token or results, but SQL and parameter values may be private. Keep them local. Incomplete drafts are allowed; Run still applies the read-only reader's validation. Worksheet limit: 256 KiB, SQL and parameter editors 64 KiB each, at most 128 parameters. Cancelling or refusing a file leaves the editor unchanged.
